# Achievement claims

Add a file named after your GitHub login, e.g. `achievements/claims/ada-lovelace.md`:

```
level: basics
name: Ada Lovelace
```

`level` is `basics`, `intermediate` or `advanced`. `name` (optional) is how you want to be listed.
See [RECOGNITION.md](../../RECOGNITION.md#track-2-achievers) for the full process.
