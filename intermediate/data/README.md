# Intermediate Sample Data

Small, non-sensitive fixtures for independent practice.

- `products.json`: product records suitable for JSON parsing and validation.
- `sales.csv`: quantity and price records suitable for CSV conversion and aggregation.
- `api_pages.json`: fake paginated API responses for use with an injected transport.
- `sample_log.txt`: a few test log lines for regex extraction and parsing.

The guided notebooks use inline demo values or temporary files so they can be run from any working directory. For optional file-based exercises, inspect `Path.cwd()` and construct an appropriate path to this folder.
