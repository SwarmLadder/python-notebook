# Level 2 — Intermediate Python (Curriculum Roadmap)

**Status:** Roadmap only. Detailed Intermediate notebooks have not yet been authored; complete [Basics](../basics/README.md) first.

## Proposed lesson sequence

1. Object-oriented programming: classes, instances, attributes, methods
2. Inheritance, composition, dataclasses, and properties
3. Comprehensions and expressive collection transformations
4. Iterables, iterators, generators, and the yield statement
5. Closures, decorators, context managers, and descriptors (introduction)
6. Functional tools: lambda, sorted keys, functools, itertools
7. Typing: annotations, generics, mypy/pyright fundamentals
8. Testing: pytest, fixtures, parametrization, mocks
9. Packaging, virtual environments, pyproject.toml, and dependency hygiene
10. JSON, HTTP requests, REST APIs, pagination, and error handling
11. SQL fundamentals with SQLite, transactions, and parameterized queries
12. Logging, configuration, CLI applications, and refactoring

## Suggested portfolio projects

- A CLI task manager with SQLite persistence
- A REST API client with retries and tests
- A packaged, typed Python utility with CI

**Prerequisites:** Comfortable with the Basics lessons and all three beginner projects.
