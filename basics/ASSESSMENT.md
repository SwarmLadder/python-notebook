# Basics Final Assessment

Complete this after the 18 lessons, lesson builds, and three projects.

## Skills checklist

- [ ] I can distinguish numbers, strings, booleans, None, lists, tuples, sets, and dictionaries.
- [ ] I can build branching and looping logic without copying code.
- [ ] I can write documented functions with explicit parameters and return values.
- [ ] I can read tracebacks and catch expected exceptions.
- [ ] I can read and write UTF-8 text and CSV using context managers.
- [ ] I can run a notebook from a fresh kernel with no hidden state.
- [ ] I can test normal, boundary, invalid, and empty inputs.

## Final capstone specification

Extend the grade manager project to accept student names and scores through optional interactive prompts; let users add records, print a sorted summary, export/import CSV, and reject malformed inputs. Separate all calculations from display and input handling. Include at least 10 assertions or equivalent manual checks.

## Suggested assessment rubric (100 points)

| Dimension | Points | Evidence |
|---|---:|---|
| Correctness | 35 | Output meets requirements on normal and boundary cases |
| Robustness | 20 | Invalid input and empty datasets handled explicitly |
| Clarity | 15 | Clear names, focused functions, useful documentation |
| Testing | 20 | Normal, negative, empty, and invalid cases covered |
| Reproducibility | 10 | Runs from a clean kernel; paths and dependencies documented |

**Readiness indicator:** Aim for 80/100 or higher, and be able to explain all code you submitted. This is a recommendation rather than an official certification.
